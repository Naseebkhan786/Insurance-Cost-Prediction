# Insurance Cost Prediction

## Project Overview
Machine Learning project to predict medical insurance charges based on customer demographics and health factors.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Flask
- HTML/CSS

## Model Performance
- Linear Regression: R² = 0.783
- Random Forest: R² = 0.864
- Tuned XGBoost: R² = 0.881

## Deployment
Flask Web Application deployed on Render.
